# ADR 0008: Internationalization for V1

## Context

规范要求避免中文硬编码散落；建议 react-i18next，并可由 ADR 决定 V1 是否启用。

## Decision

**V1 启用 react-i18next + i18next**，建立 `zh-CN`（完整）与 `en-US`（骨架 key）。业务文案走 message 层，禁止组件内硬编码用户可见字符串。

## Alternatives

- 仅自研 message map：轻，但后续切 i18n 成本高。
- V1 完全不做：容易散落硬编码，违背规范。

## Consequences

- Phase 0 即接入 provider 与基础字典。
- 英文可先回退到中文或 key，不阻塞功能。
